# Deep-learning extras for hermod-ml (pytorch_mlp, keras_mlp), fully pinned
# (direct and transitive). Installed on top of requirements.txt, never alone:
# the Docker build does so when HERMOD_ML_EXTRAS=dl, giving the "-dl" image.
#
# Every pin ships CPU-only wheels for CPython 3.12 (the Docker image) and
# resolves against requirements.txt unchanged:
# - torch comes from the PyTorch CPU index ("+cpu" local versions exist only
#   there, so no PyPI package can shadow it). The PyPI torch wheel would pull
#   ~3 GB of CUDA libraries.
# - tensorflow-cpu 2.20.0 is the release that fits the base pins: 2.21 needs
#   protobuf>=6.31.1 (base pins protobuf 5.29.5 for onnx 1.18), and 2.18/2.19
#   cap numpy below 2.1/2.2 (base pins numpy 2.2.6).
# - tf2onnx 1.17.0 is the first release that accepts protobuf 5 and numpy 2;
#   1.16.1 pins protobuf~=3.20.
# - torch 2.9.1 still has the TorchScript ONNX exporter (dynamo=False), which
#   needs no onnxscript; deep.py uses it.
